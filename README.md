# HVPQ / PIQ / Q88 / Class Status Checker v9

Extraction-first checker for HVPQ, PIQ, Q88 and Class Status.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Optional local LLM

Install Ollama locally and run a model, for example:

```bash
ollama pull qwen2.5:14b
ollama run qwen2.5:14b
```

Then enable **Use local LLM extraction assist** in the sidebar.

The LLM is used only to improve structured extraction. Final findings are generated by deterministic Python rules.
